# UniGPA Pakistan

A modern, responsive GPA calculator for Pakistani universities, built with **HTML, CSS, and JavaScript**. Students can calculate their semester GPA using university-specific grading policies through a simple and interactive interface.


## Features

- Supports multiple Pakistani universities (NUST, FAST, COMSATS, MUET, NED, KU, PU, Bahria, SZABIST, IBA Karachi, Air University, University of Sindh)
- University-specific grading policies
- Add multiple courses dynamically
- Enter course name, credit hours, and grade
- Automatic Semester GPA calculation
- Academic summary showing:
  - Total Subjects
  - Total Credit Hours
  - Total Quality Points
  - Semester GPA
- Light and Dark Mode
- Fully responsive layout for mobile devices
- Built with Vanilla JavaScript (no frameworks or libraries)



## Built With

- **HTML5**
- **CSS3** (custom styles + media queries)
- **JavaScript (ES6)**
- **DOM Manipulation**



##  How to Use

1. Select your university.
2. Enter your course name, credit hours, and grade.
3. Click **Add Course** to add more subjects.
4. Click **Calculate GPA**.
5. View your academic summary.
6. Click **Calculate Again** to start over.

2. Open the project folder
