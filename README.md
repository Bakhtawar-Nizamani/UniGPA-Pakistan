#  UniGPA Pakistan

A modern GPA calculator for Pakistani universities built with **HTML, CSS, and JavaScript**. It allows students to calculate their semester GPA using university-specific grading policies through a simple and interactive interface.

# Features

- Supports multiple Pakistani universities
- University-specific grading policies
- Add multiple courses dynamically
- Enter course name, credit hours, and grade
- Automatic Semester GPA calculation
- Displays:
  - Total Subjects
  - Total Credit Hours
  - Total Quality Points
  - Semester GPA
- Light & Dark Mode
-  Built with Vanilla JavaScript (DOM Manipulation)

# Built With

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation

# How to Use

1. Select your university.
2. Enter your course details.
3. Add more courses if needed.
4. Click **Calculate GPA**.
5. View your academic summary.
